# SRAPP

Sistema de registro de asistencias para Prácticas Pre Profesionales de la UTM.

- Genera la ficha de asistencia en blanco o lista para firmar.
- Guarda los datos solo en el navegador.
- Permite exportar la información a PDF.
- Soporta modo claro y oscuro.

## Desarrollo

```bash
pnpm install
pnpm run dev
```

## Producción

```bash
pnpm run build
```
